# 🎓 Student Management System

A web-based **Student Management System** built using **PHP, MySQL, HTML, CSS, and JavaScript**.  
This system helps administrators manage student records efficiently, including adding, updating, searching, and deleting student information.

---

## 📌 Project Overview

The Student Management System is designed to simplify the management of student data in an educational institution.  
It provides a secure admin login and an easy-to-use interface for handling student records.

This project was developed as part of an **academic requirement** and focuses on core CRUD operations with proper database integration.

---

## ✨ Features

- 🔐 Admin Login & Logout
- ➕ Add New Students
- ✏️ Update Student Information
- ❌ Delete Student Records
- 🔍 Search Students by ID or Name
- 📄 View All Students in a Table
- 🗄️ MySQL Database Integration
- 🖥️ Clean and User-Friendly Interface

## ⚙️ Installation & Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/sagardonut/StudentManagementSystem.git
  ```

2. Move the project folder to:
   ```
   C:/xampp/htdocs/
   ```

3. Start **Apache** and **MySQL** from XAMPP / WAMP.

4. Open **phpMyAdmin**:
   - Create a database named `student_management`
   - Import the `database.sql` file

5. Configure the database connection in:
   ```
   config/db.php
   ```

6. Open the project in your browser:
   ```
   http://localhost/StudentManagementSystem
   ```
